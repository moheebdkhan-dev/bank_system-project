# bank_system-project
A bank system that simulates real bank systems, I built this project to practice functional/procedural programming, This bank system stores data in files as a database. A user logs in by username and password, and each user has permissions to access specific menus, The main menu has many options: Show clients list, Add new client, Delete client, Update client, find client by account number, Transactions, Manage users and log out.
In transaction menu, There are 4 options: Deposit, Withdraw, Show total balances and Go back to main menu.
In manage users menu, There are many options: Show users list, Add new user, Delete user, Update user, Find user by username and Go back to main menu.
Permissions are represented in binary, When i need to check the permission, I execute a bitwise and operator.
